# Landing page guidelines

These rules outrank your defaults for this project.

## Honesty
- No invented customer counts, logos, awards, testimonials or revenue figures. Use bracketed placeholders like `[customer name]` and list them under the page before finishing.
- Every claim a visitor can check must be checkable. If a number is needed and none was given, write the placeholder instead of a plausible guess.

## Legibility
- Body text ≥ 16px, and never below 14px anywhere. Line length 45–75 characters for paragraphs.
- Contrast ≥ 4.5:1 for body text and ≥ 3:1 for large text and UI borders. Check the muted colours against the page background, not against white.
- One emphasis action per section. A second CTA competes with the first; use a text link instead.

## Structure
- Mobile-first: the layout must hold at 360px wide before any breakpoint. Test 360, 768 and 1280.
- The hero states what this is, for whom, in one headline (≤ 8 words) and one sentence. No feature lists in the hero.
- Every section has one job. If a section needs two headlines, it is two sections.

## Behaviour
- Focus states visible on every interactive element; keyboard order follows reading order.
- Links say where they go ("Read the docs"), never "click here".
- Nothing animates on scroll. Respect `prefers-reduced-motion`.
